# Minute Media

> Minute Media is a global technology, media and advertising company. It operates
> owned-and-operated sports and entertainment brands (Sports Illustrated, The Players'
> Tribune, 90min, Mental Floss, FanSided, The Big Lead, DBLTAP) and licenses publishing
> and monetization technology to third-party publishers — the STN Online Video Platform
> (acquired as STN Video / SendtoNews in January 2024), the Minute Media SSP, and
> ad-management solutions. Minute Media publishes no developer portal, no API reference
> and no machine-readable API definition. Two real API surfaces are nevertheless live and
> were verified by probe on 2026-08-12: a public oEmbed 1.0 endpoint, and a
> credential-gated publisher API whose only public client is the company's own WordPress
> plugin.

This file was generated by API Evangelist from probed evidence, not published by Minute
Media. Nothing here is a vendor claim.

## APIs

- [STN Video oEmbed API](https://embed.sendtonews.com/services/oembed): Public,
  unauthenticated oEmbed 1.0 provider endpoint. GET with `url` (a URL-encoded
  embed.sendtonews.com resource containing `SC=<share-code>` or `fk=<video-key>`) and
  `format` (`json` or `xml`). Returns a type `video` oEmbed payload with provider_name,
  author_name, title, width, height, cache_age and the player `html`. Verified 200 on
  2026-08-12. Calling it without a resolvable `url` returns 400 "url must include SC or fk".
- [STN Video Publisher API](https://api.sendtonews.com/api/v1/): Credential-gated. Every
  operation is a POST carrying `cid` (Company ID) and `authcode` (Authentication Code) in
  the request body. Known operations, read from the provider's own plugin:
  `auth/verifycode`, `players`, `categories`, `stories`. Verified live: an unauthenticated
  POST returns 422 with `{"success":false,"code":422,"errors":{...}}`. Credentials are not
  self-serve — publishers request them from publishers@stnvideo.com.

## Specs

- No OpenAPI, Swagger, GraphQL, AsyncAPI or MCP manifest is published. Contract discovery
  probed /openapi.json, /openapi.yaml, /swagger.json, /v1/openapi.json, /api-docs, /docs,
  /redoc, /graphql, and every /.well-known/ path across www.minutemedia.com,
  minutemedia.com, www.stnvideo.com, stnvideo.com, www.ovp.stnvideo.com, api.stnvideo.com,
  api.sendtonews.com, embed.sendtonews.com and amp.stnvideo.com. Every one returned 404;
  pub.stnvideo.com returned 503 to our client.
- No A2A agent card at /.well-known/agent-card.json or /.well-known/agent.json on any host.
- No security.txt, no OpenID/OAuth discovery document, no API catalog.
